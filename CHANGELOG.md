# Changelog

## v1.0.0 (2026-07-25)

### ✨ Features
- **Dashboard**: Revenue overview, best sellers, transaction stats
- **POS**: Cafe POS with item selection and payment
- **CRUD**: Products, Categories, Mejas management
- **Auth**: Login with JWT, role-based access
- **Guest History**: View past transactions via phone number
- **Config**: AppConfig interface with dynamic pricing display

### 🎨 UI/UX
- Dark theme (#131313) with neon green (#6bfb9a)
- Glassmorphism cards
- Responsive layout (mobile + desktop)
- Shadcn/ui components

### 🧰 Technical
- Next.js with TypeScript
- Tailwind CSS v4
- Shadcn/ui component library
- Server-side rendering ready
